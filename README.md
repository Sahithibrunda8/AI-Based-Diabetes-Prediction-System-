# AI-Based Diabetes Prediction System

Machine Learning based diabetes prediction system using Random Forest and Streamlit.

## Features

 Diabetes prediction using health indicators
 Random Forest Classifier
 Streamlit web application
 Performance evaluation metrics
 Data visualization

## Technologies Used

 Python
 Pandas
 NumPy
 Scikit-learn
 Streamlit
 Matplotlib
 Seaborn

## Run Project

```bash
streamlit run app.py
```

## Project Files

 `app.py` - Streamlit web application
 `preprocess_training_model.py` - Model training and preprocessing
 `model.pkl` - Saved trained model
 `scaler.pkl` -  Saved scaler
 `metrics.pkl` - Evaluation metrics
 `feature_names.pkl` - Feature names
